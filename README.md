# Synthia - 自拍生成写真

一个基于React和Vite的网页应用，用于将自拍转换为高质量写真图片。

## 功能特点

- **图片上传**：支持点击上传和拖拽上传多张图片
- **图片预览**：上传后可预览图片并删除不需要的图片
- **描述词选择**：内置9种预置描述词，包括专业写真、艺术肖像、时尚杂志风格、酒吧氛围等
- **AI生成**：调用豆包API生成对应风格的写真图片
- **结果展示**：以网格形式展示生成的写真结果

## 技术栈

- React 18
- Vite
- JavaScript

## 快速开始

1. 克隆项目到本地
2. 安装依赖
   ```bash
   npm install
   ```
3. 配置API密钥
   - 复制 `.env` 文件并将其重命名为 `.env.local`
   - 在 `.env.local` 文件中设置你的豆包API密钥：
     ```
     VITE_DOUBAO_API_KEY=你的API密钥
     ```
4. 启动开发服务器
   ```bash
   npm run dev
   ```
5. 在浏览器中访问 `http://localhost:5173`

## 使用说明

1. **上传图片**：点击或拖拽图片到上传区域
2. **选择描述词**：从预置的描述词中选择一个风格
3. **生成写真**：点击"生成写真"按钮
4. **查看结果**：等待生成完成后，查看生成的写真图片

## 注意事项

- 请确保上传的是清晰的自拍正脸照片
- 生成过程可能需要几秒钟时间
- 实际项目中需要替换为真实的豆包API调用
